0x00 🛠️ 实用工具

1. GitHub Agentic Workflows：让 AI Agent 自动维护你的仓库

一句话：GitHub 在 2026 年 6 月 11 日发布了 Agentic Workflows 公开预览——用 Markdown 写工作流，AI Agent 自动处理 Issue Triage、CI 故障修复、文档更新、代码审查等任务。

核心功能：

  • 用 gh aw init 创建 Agentic Workflow，Markdown 文件定义 Agent 要完成的任务
  • gh aw CLI 自动编译 Markdown → GitHub Actions YAML
  • 支持 Copilot CLI、Claude Code 等多种 Agent
  • 安全设计：沙箱隔离（Sandboxed Container）、只读权限默认、Agent Workflow Firewall、Safe Outputs Gate
  • AI Credits 计费：按 AI Credits 计费，不再需要 Personal Access Token
  • 预置工作流模板：Issue triage、CI failure analysis、compliance reporting

适合人群：所有 GitHub 使用者——开源维护者、DevOps 工程师、开发团队

获得路径：gh aw init（需 GitHub CLI + Agentic Workflows 公开预览权限）

比如你可以写一个工作流：「当 Issue 被标记为 bug 时，让 Agent 分析代码、定位根因、生成修复 PR」——全程自动化，你只需要审核 PR。

2. Anthropic Claude Code Dispatch + Channels：用手机遥控你的桌面 AI

一句话：Anthropic 在 2026 年 3 月连续发布 Dispatch 和 Channels——Dispatch 让你从手机扫码连接桌面 Claude，Channels 让 Claude 通过 Telegram/Discord 接收外部事件。

核心功能：

  • Dispatch：手机扫个 QR Code 就能远程交办任务给桌面端的 Claude——无需任何技术配置，面向普通人的「远程 AI 助手」
  • Channels：开发者版，通过 Telegram/Discord 向运行的 Claude Code 发送指令，支持 CI 告警、生产错误、PR 评论等外部事件触发
  • 支持 MCP 插件架构，可扩展 Slack、邮件等 Channel
  • Always-on Session：保持连续对话和大型上下文窗口

适合人群：所有人——Dispatch 面向普通用户，Channels 面向开发者

获得路径：

  • Dispatch：Claude.ai 桌面版扫码使用
  • Channels：code.claude.com — 安装 Telegram/Discord 插件

3. CLI-Anything：把 Blender/GIMP/FreeCAD 变成 AI 可控工具

一句话：CLI-Anything（港大开源）可以将任何 GUI 桌面软件转化为 AI Agent 可调用的 CLI 工具，让 AI 像操控 API 一样操控桌面软件。

核心功能：

  • 支持 Blender、GIMP、FreeCAD、OBS Studio、Audacity、Zotero 等主流桌面软件
  • FreeCAD 内置 258 条 AI 可调用命令
  • 输出结构化 JSON，天然适配各种 AI Agent
  • 支持交互式 REPL 模式

实测场景：AI Agent 通过 CLI 接口操控 Blender 完成 3D 机械零件参数化建模 + 逼真渲染，全程无需人工操作 GUI。

适合人群：3D 设计师、视频创作者、AI 工程师

获得路径：pip install cli-anything 或 GitHub 开源

来源

4. OpenClaw（已更名为 Moltbot）：开源 AI 电脑助手

一句话：OpenClaw（现名 Moltbot）是目前最火的开源 AI Agent 框架——361K+ GitHub Stars，能让 AI 像人类一样操作电脑。

核心功能：

  • 软件操控：打开浏览器、填写表单、操作文件系统
  • Agent Skills 市场：社区贡献的预设技能
  • 已部署在 DigitalOcean 1-Click 市场
  • 微软基于 OpenClaw 构建了 Scout（首个 Agentic AI 产品）

适合人群：想体验 AI 自动化操作电脑的普通用户

获得路径：GitHub 开源 或 DigitalOcean 一键部署

0x01 🎨 创意场景

5. MCP 2026-07-28 RC：AI Agent 互通标准大升级

一句话：MCP（Model Context Protocol）的 2026-07-28 版本 RC 发布——这是协议自发布以来最大的一次更新，包含无状态核心、MCP Apps、Tasks 扩展和正式弃用政策。

核心功能（对普通用户的意义）：

  • 无状态核心：MCP Server 可以水平扩展，部署成本大幅降低 → 更多免费的 MCP 服务出现
  • MCP Apps：服务器可以渲染交互式 HTML 界面，AI 聊天框里直接操作表单/按钮/图表
  • Tasks 扩展：支持长时间运行的任务（如「分析 100 页 PDF 并生成报告」）
  • 完整 JSON Schema 2020-12：工具参数定义更灵活
  • 正式弃用政策：协议有 9 个月迁移窗口，不会突然破坏你已有的集成

适合人群：所有 AI 工具的使用者——MCP 生态的壮大意味着更多 AI 工具可以互通

获得路径：最终规范预计 2026 年 7 月 28 日发布

6. Suprmind：让 5 个 AI 模型在同一个聊天框里辩论

一句话：Suprmind 是一个多模型协作平台——让 GPT、Claude、Gemini、Perplexity 和 Grok 在同一个聊天框里讨论、辩论、协作。

核心功能：

  • 辩论模式：让多个 AI 模型就同一问题展开辩论，你作为裁判选最优答案
  • 协作模式：分角色协作（一个写框架、一个写细节、一个审代码）
  • 投票模式：多个模型给出答案后投票，少数服从多数
  • 实时聊天：你可以实时加入 AI 们的讨论

适合人群：需要高质量输出的人——研究者、写作者、决策者

获得路径：suprmind.ai — 免费版支持 3 个模型

0x02 🤖 开源项目

7. FlowPrompt：可视化无代码 AI 工作流编排

一句话：FlowPrompt 是一个可视化、无代码的 AI 工作流编排平台——拖拽节点就能搭建复杂的 AI 自动化流程。

核心功能：

  • 可视化画布：拖拽 LLM、搜索、文件处理、API 调用等节点
  • 支持多模型：GPT、Claude、Gemini、本地模型
  • 输出可作为下一个节点的输入（Pipeline 模式）
  • 支持定时触发和 Webhook 触发

适合人群：不想写代码但想搭建 AI 自动化流程的非技术人员

获得路径：官网注册（免费版可用）

[来源：优设 2026 年 6 月设计干货合集]

8. Vellum：本地优先的个人 AI 助手

一句话：Vellum 是一个开源、本地优先的 macOS AI 助手——凭证隔离、持久记忆、原生桌面操控。

核心功能：

  • 凭证隔离：你的 API Key 永远不暴露给模型
  • 持久记忆：它真的「认识你」——记住你的偏好、项目、工作习惯
  • 原生 macOS 桌面控制：可以操作文件、发送通知、管理日程
  • 免费 + 云托管可选

适合人群：注重隐私且需要 AI 助手帮忙管理工作效率的人

获得路径：vellum.ai — 开源免费

0x03 🎮 AI 娱乐

9. Claude Fable 5：更安全的通用 AI 模型

一句话：Anthropic 发布了 Claude Fable 5（Mythos 级模型）——更强的编程、知识工作、视觉、记忆和长上下文能力，且已通过安全对齐可用于一般场景。

核心功能：

  • 编程能力：复杂的多文件重构、大型代码库理解
  • 知识工作：长文档分析、研究报告撰写
  • 视觉：多模态理解（截图、图表、手写笔记）
  • 记忆：跨会话上下文保持
  • 长上下文：1M token 上下文窗口

适合人群：所有 Claude 用户——Claude.ai 和 Claude Code 均已可用

获得路径：Claude.ai / Claude Code 默认模型（需 Claude Max 订阅）

[来源：Anthropic Release Notes 2026]

10. 用 Claude Code + HeyGen MCP 一键生成 AI 视频

一句话：通过 Claude Code 的 MCP 集成，一条提示词就能完成脚本写作、语音克隆、虚拟人渲染和视频编辑——全 AI 自动完成。

核心功能：

  • Claude Code 通过 MCP 协议调用 HeyGen
  • 自动写脚本 + 克隆你的声音 + 生成虚拟人 + 渲染 + 剪辑
  • 从一条 Prompt 到完整视频，全程无需手动操作

适合人群：视频创作者、内容营销人员、自媒体运营

获得路径：Claude Code + HeyGen MCP 插件

0x04 🏠 生活应用

11. Perplexity：AI 搜索持续进化

一句话：Perplexity 已成为信息搜索首选——综合多个来源给出结构化回答，精确标注每个信息的来源。

核心功能：

  • 深度搜索：可搜索 PDF/学术论文，支持中文
  • 专业搜索：金融数据、学术论文、法律条文等垂直领域
  • 自动引用来源（点击直接跳转原文）
  • 免费版足够日常使用

适合人群：所有人

获得路径：perplexity.ai — 免费版即可

[来源：Perplexity 官网]

12. Gamma：AI 秒变 PPT 制作高手

一句话：输入主题，2 分钟生成排版精美、内容完整的演示文稿——适合教师、职场人士和学生。

核心功能：

  • 支持中文输入，自动匹配设计风格
  • 生成后可在线演示或导出 PDF/PPTX
  • 内置商务、教育、科技、医疗等模板
  • 免费版可用大部分功能，无水印

适合人群：教师、职场人士、创业者、学生

获得路径：gamma.app — 免费注册

0x05 ⚡ 效率神器

13. Android CLI：Google 官方无头 Android 开发工具

一句话：2026 Google I/O 发布的 Android CLI——在命令行中完成全部 Android 开发流程，无需 IDE。

核心功能：

  • android-cli create project — 创建 Android 项目
  • android-cli emulator run — 运行模拟器
  • android-cli test run — 运行测试
  • 配合 Cursor/Claude Code 全自动开发 Android App
  • 无需 Android Studio，完全无图形界面

适合人群：希望用 AI 辅助开发 Android 应用的开发者

获得路径：brew install android-cli / Android Developers 官网

[来源：Android Developers Blog]
