🛠️ 实用工具

1. Storyflow——AI 画布式协作空间

一句话简介：将笔记、白板、AI 对话整合到一块无限画布上。
核心功能：用自然语言生成流程图、思维导图、演示文稿；AI 根据画布内容自动生成摘要和下一步建议；多人实时协作。
适合人群：知识工作者、产品经理、教育工作者。
获得路径：storyflow.so（免费套餐每月 50 个 AI 生成点）
来源

2. Suno AI 3.0——你的 AI 音乐制作人

一句话简介：输入歌词和风格，AI 生成完整歌曲（带人声和编曲）。
核心功能：支持中文歌词生成；可选择风格（民谣/摇滚/电子/R&B）；生成速度 <30 秒；可下载为 MP3。
适合人群：音乐爱好者、播客创作者、短视频制作者。
获得路径：suno.ai（每日免费 5 次生成）
来源

3. Replit Agent——用自然语言写 Web 应用

一句话简介：描述你想要的应用，Replit Agent 自动完成全栈开发。
核心功能：输入「帮我做一个团队任务看板，支持拖拽排序和成员分配」→ Agent 自动生成前后端代码、部署上线；可交互式修改（「改成暗色模式」）；支持导出源代码。
适合人群：非程序员的产品经理、创业者、设计师。
获得路径：replit.com（免费套餐每月 50 次 Agent 调用）
来源

4. Recall——AI 记忆助手，再也不会忘记

一句话简介：自动记录你的电脑屏幕内容，支持自然语言搜索回忆。
核心功能：后台自动截图（5s/张）；OCR 识别 + AI 理解内容；输入「上周三下午讨论的那个设计稿」自动找到；可标记重要时刻。
适合人群：信息过载的打工人、多任务切换频繁的开发者、学生。
获得路径：recall.ai（免费套餐 7 天录像保留）

🎨 创意场景

5. NotebookLM——你的超级研究助理

一句话简介：上传 PDF/网页/YouTube 链接，AI 为你生成研究笔记和播客对谈。
核心功能：支持上传 50 个源文件（每个最多 500 页）；自动生成研究摘要、关键引文、对比分析；最惊艳的功能——生成「AI 播客」（两个 AI 主持人对谈你的研究内容）。
适合人群：学生、研究人员、任何需要深度阅读的人。
获得路径：notebooklm.google.com（免费，Google 账户登录）
来源

6. 我用 Cursor + Claude 搭建了个人知识库

一句话简介：用 Cursor 编辑器 + Claude API 搭建属于你自己的 RAG 知识库，无需写代码。
核心功能：拖拽文档到知识库 → AI 自动索引 → 用自然语言提问；支持 PDF/Word/Markdown/网页；可分享知识库给团队。
适合人群：对数据隐私有要求的个人/小团队。
获得路径：使用 Cursor 的「Knowledge Base」功能（免费版支持 3 个知识库），配合 Claude/OpenAI API Key。

🤖 开源项目

7. Diffusers 社区模型——2000+ 免费 AI 图像模型

一句话简介：HuggingFace Diffusers 社区有 2000+ 免费的图像生成模型，不需要 GPU。
核心功能：文本生成图像、图像转图像、图像修复（inpainting）; 通过 HuggingFace Spaces 在线运行（免费 CPU/GPU）；支持 ComfyUI 工作流导入。
适合人群：设计师、艺术创作者。
获得路径：huggingface.co/models?pipeline_tag=text-to-image（免费）
来源

8. Aider——终端里的 AI 编程助手

一句话简介：纯终端、支持所有主流编程语言的 AI 结对编程工具。
核心功能：连接 Claude/OpenAI/Gemini；支持自动 git commit、代码审查、重构；理解整个代码仓库（不止单个文件）；无需 GUI，SSH 到服务器也能用。
适合人群：开发者（特别是喜欢终端的）。
获得路径：pip install aider-chat（开源免费，需要自己的 API Key）

🏠 生活应用

9. AI 旅行规划——用 ChatGPT/Copilot 定制行程

一句话简介：告诉 AI 你的预算/兴趣/天数，AI 生成完整旅行计划。
核心功能：输入「3 天成都美食之旅，预算 2000 元，喜欢街头小吃和历史文化」→ AI 生成每日行程 + 交通建议 + 预算分摊 + 避坑提示；支持导出为日历文件。
适合人群：所有喜欢旅行但不想做攻略的人。
获得路径：任何大模型聊天工具均可（ChatGPT/Claude/Copilot 等），免费。
来源

10. AI 家庭作业助手——Explainpaper

一句话简介：上传论文/教材，标注看不懂的段落，AI 用简单语言解释。
核心功能：上传 PDF 后点击任意段落，AI 立刻用通俗语言解释；支持追问（「这个推导过程再详细一点」）；自动生成学习摘要和测试题。
适合人群：学生、自学者。
获得路径：explainpaper.com（每月免费 3 篇论文）

核心功能：基于 OpenAI Whisper 的本地版本，完全离线运行；支持中英文混说、专业术语；自动格式化标点和分段；可指定输出风格（正式/口语）。
适合人群：需要写大量文档/笔记/邮件的人。
获得路径：superwhisper.com（免费版每小时 30 分钟）

核心功能：支持输入格式：文本/JSON/Markdown；输出风格可选（简洁/详细/PPT 风格）；自动提取关键成果和数据指标。
适合人群：所有需要写周报的打工人。
